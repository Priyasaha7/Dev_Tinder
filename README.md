DevTinder 🔥

A Tinder for Developers

📌 About the Project

Devtinder is a developer-focused platform designed to connect developers based on skills, interests, and tech stacks.
Just like Tinder, but instead of dating, the goal is networking, collaboration, learning, and building projects together.

⚙️ Setup & Installation
1️⃣ Initialize the project
npm init

2️⃣ Install Express
npm install express

3️⃣ Start the server
npm start


For development mode (with nodemon):

npm run dev

🌐 Server Details

Server runs on port 7777

Basic routes implemented:

/ → Home page

/hello → Hello response

/test → Test server response
